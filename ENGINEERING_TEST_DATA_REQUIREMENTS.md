# Engineering Test Data Required for Publication

Use one completed record per model and test. Do not publish estimates, reconstructed values, or certification limits as measured results.

## Required identification

- Model and hardware revision
- Sample quantity and sample IDs
- Test date and internal report number
- Test owner / laboratory
- Firmware or power-board revision, if applicable

## Required test conditions

- Input voltage and frequency
- Ambient temperature and humidity
- Product orientation and mounting condition
- Port loading / AC loading for every output
- Cable type and rating
- Test duration and sampling interval
- Instrument manufacturer, model and calibration status
- Exact measurement points, preferably with an annotated image

## Required results

- Time-series readings, not only the peak value
- Peak, minimum and steady-state readings
- Pass/fail criterion and its source
- Pre-test and post-test functional checks
- Abnormal behavior, shutdown or protection events
- Photos or screenshots tied to the sample ID and time

## Priority records

1. NT011-US 70W sustained-load thermal test: add ambient temperature, input, load allocation, orientation, measurement point, instrument and temperature-over-time readings.
2. NT011-US multi-port power allocation test: publish C1/C2/C3/A combinations and measured output behavior.
3. NT011-US wall-stability / anti-sag test: publish socket fixture, insertion condition, angle/displacement and repeated-use result.
4. Power strip full-load temperature test by regional platform.
5. Power strip grounding continuity, cord anchorage and overload/protection records where applicable.

### Conversion rule
Every high-intent content page should contain:
1. One link to the relevant product/category page.
2. One link to a proof page (testing/manufacturing/QC).
3. One direct RFQ CTA.

## GEO content format for priority pages
Each P0/P1 page should contain an answer-first block near the top:
- What it is / who it is for.
- 3-5 concrete facts.
- Buyer implication.
- Relevant LONGRICH product or factory capability.
- Link to supporting test / product / RFQ page.

Avoid unsupported marketing claims. Prefer measurable facts, model names, power classes, test conditions, markets, production capabilities, and explicit OEM/ODM scope.

## First 30-day execution order

### Week 1 — Index and query baseline
- Confirm index status for all P0 pages.
- Record GSC impressions / clicks / average position for P0 queries.
- Request indexing only for P0 pages that remain unknown/not indexed after validation.

### Week 2 — P0 on-page strengthening
- Strengthen titles/H1/meta only where keyword intent is not explicit.
- Add 3-way internal linking: commercial -> proof -> product -> RFQ.
- Add answer-first factual blocks to Manufacturer, OEM/ODM, Universal, GaN, NT011-US.

### Week 3 — GEO proof strengthening
- Improve 70W test, grounding, wall stability, durability, QC pages.
- Add concise factual summaries suitable for AI extraction.
- Add cross-links from every proof page to a relevant product and RFQ.

### Week 4 — Measure and iterate
- Compare P0 page impressions week-over-week.
- Identify queries with impressions but low CTR -> improve title/meta.
- Identify queries ranking 8-30 -> expand the matching page before creating new content.
- Create new pages only where Search Console shows a clear content gap.

## KPI dashboard
Do not use Lighthouse as the primary KPI anymore.

Track weekly:
- Indexed P0 pages / total P0 pages
- Google impressions
- Organic clicks
- Queries entering Top 30 / Top 10
- Top landing pages
- RFQ page views
- RFQ clicks / email clicks / WhatsApp clicks
- Organic visit -> inquiry conversion rate

## Current strategic principle
Do not publish dozens of generic articles. First make 10-15 existing high-value pages strong enough to earn impressions, citations and inquiries.

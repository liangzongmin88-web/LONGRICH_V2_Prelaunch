## Weekly GSC capture
Every weekly review, record:

- Site-wide clicks
- Site-wide impressions
- Site-wide CTR
- Site-wide average position
- Indexed priority pages / total priority pages
- Top 10 queries by impressions
- Pages with >20 impressions and 0 clicks
- Pages with average position 4–20
- New queries that contain manufacturer / OEM / ODM / factory / supplier
- New model queries (NT009, NT010, NT011, TUS, WPG, ECS)

## Decision rules
1. **Do not edit a page twice within 7 days** unless there is a technical error.
2. **Top 1–10 + low sample size:** preserve ranking and collect more data.
3. **Top 8–30 + relevant commercial query:** improve the existing page before creating a new one.
4. **High impressions + 0 clicks:** prioritize title/meta CTR work.
5. **Clicks but no inquiry actions:** strengthen RFQ, email and WhatsApp conversion path.
6. **No query rows:** widen date range to 3 months before changing the page.
7. **Already indexed:** do not repeatedly request indexing unless the page materially changed.
8. **Non-www URL:** rely on the permanent redirect to the canonical www URL; never request indexing for the non-www variant.
